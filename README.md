# tally

Count the words in a text file: `tally notes.txt`.

For scripts, `tally --json notes.txt` prints the counts as one line of JSON: `{"total":5,"unique":4}`.

This is the small demo project used in the [Implementator Lite docs](https://jakublukaszuk.github.io/implementator-lite-docs/) and its videos. The tag `demo-start` marks the state each recording begins from.
